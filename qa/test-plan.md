# Тест-план проекта Cherry Cake (QA Suite)

## 1. Введение и цели
Настоящий тест-план определяет стратегию, приоритеты, виды тестирования и критерии выхода для обеспечения стабильности и соответствия спецификации кондитерской «Cherry Cake».
Ключевая цель: 100% совпадение математических расчётов (цены, НДС, пороги, скидки, доставка) в БД, API, CSV, PDF и пользовательском интерфейсе.

## 2. Зоны ответственности (RACI)
- **QA Java #1 (Расчёты и Каталог)**: Формулы расчёта `PriceCalculatorService`, валидация порогов скидок, применение промокодов, округление HALF_UP, проверка регионального каталога и доступности товаров.
- **QA Java #2 (Заказы, Бронь, Отчёты)**: Жизненный цикл заказов (PICKUP/DELIVERY), валидация тайм-слотов и capacity, алгоритм распределения столиков бронирования и окно конфликтов $\pm 2$ часа, матрица RBAC (4 роли $\times$ 10 эндпоинтов), сверка отчётов SQL = JSON = CSV = PDF.
- **QA Frontend**: Доступность WCAG AA, адаптивная верстка (320px, 768px, 1200px), фокус-менеджмент, валидация 15 правил ввода в формах, проверка всех `data-testid`.

## 3. Объекты тестирования
1. **Калькулятор цен (`/api/cart/calculate`)**:
   - Формула: Subtotal $\to$ VAT $\to$ Amount with VAT $\to$ Max(Discount) $\to$ Delivery Fee $\to$ Total.
   - Округление: `BigDecimal.setScale(2, RoundingMode.HALF_UP)` на каждом шаге.
   - Ставки НДС и скидок: строго как десятичные доли (`vatRate`: 0.12, `discountRate`: 0.05).
2. **Каталог товаров (`/api/products`, `/api/categories`, `/api/regions`)**:
   - Обязательный параметр `?region={code}`. Ошибки 400 при отсутствии, 404 при неверном регионе.
   - Модификаторы SINGLE (только 1) и MULTI, проверка `isRequired`.
3. **Оформление заказов (`/api/orders`)**:
   - Серверный пересчёт стоимости (игнорирование клиентских сумм).
   - Тайм-слоты: capacity, параллельные бронирования, код 409 при переполнении.
   - Нумерация: маска `CC-YYYY-XXXXXX`.
4. **Бронирование столиков (`/api/bookings`)**:
   - Столики 1–12, жадный подбор по минимальной вместимости $\ge$ гостей.
   - Окно пересечения $\pm 2$ часа.
   - Нумерация: маска `BK-YYYY-XXXXXX`.
5. **Отчёты о продажах (`/api/reports/sales`)**:
   - Фильтры по датам, региону, группировке (REGION/MONTH).
   - Доступ: роли VIEWER, STAFF, ADMIN.
   - Экспорт: CSV (UTF-8 with BOM), PDF (таблица + гистограмма).
6. **Ролевой доступ (RBAC)**:
   - Роли: CUSTOMER, VIEWER, STAFF, ADMIN.
   - Защита путей `/api/reports/**`, `/api/admin/**`, `/api/orders/my`.

## 4. Критерии входа и выхода
- **Критерии входа**:
  - Успешная компиляция проекта.
  - Накатанные миграции Flyway (V1..V5).
  - Наличие базовых сидов (регионы UZ, KZ, RU, товары, слоты, промокод PROMO10).
- **Критерии выхода**:
  - 100% прохождение unit и integration тестов (`mvn test`).
  - 0 нарушений Checkstyle (`mvn checkstyle:check`).
  - 27/27 расчетных тест-кейсов калькулятора (C01–C27) подтверждены.
  - 11/11 сценариев заказов (O01–O11) подтверждены.
  - 6/6 сценариев бронирования (B01–B06) подтверждены.
  - 0 Critical и 0 High дефектов в баг-трекере.
  - Lighthouse Accessibility $\ge$ 90, axe 0 critical/serious.
