3. Детали
CC-11. Каркас
npm create vite@latest (React, JavaScript), Node LTS. Зависимости: react-router-dom, @reduxjs/toolkit, react-redux, axios, chart.js; для разработки eslint, prettier, vitest, @testing-library/react.
Папки src/: api, components/ui, components/layout, pages, store, hooks, utils, constants, styles, mocks. Файлы .env и .env.example: VITE_API_BASE_URL и VITE_DEFAULT_REGION.
Роуты: Home, Menu, Cart, Checkout, Reports, UiKit; для бонуса позже Booking. Все пока страницы-заглушки. Скрипты dev, build, lint, test.
Store: slice region (выбранная страна), cart (позиции), ui (тосты и загрузка). Ключи localStorage: cc_region, cc_cart.
api/client.js: базовый адрес из VITE_API_BASE_URL; ошибка ответа превращается в тост; единый формат ErrorResponse.
CC-12. Токены и UI-кит
Токены в styles/tokens.css по таблице от AS: цвета, шрифты, отступы 4–64 px, радиусы 4 и 8, брейкпоинты 320 / 768 / 1200, область нажатия 44 px.
Минимальный набор к четвергу: Button, Input, Card, Modal. Остальное в четверг–пятницу: Select, Checkbox, Radio, Toast, Loader, Badge, EmptyState, ErrorState.
Состояния каждого компонента: hover, focus-visible (кольцо 2 px), active, disabled, loading, error. У полей обязательна подпись label.
Страница /ui-kit показывает все компоненты во всех состояниях; её проверяет QAF.
CC-14 и CC-26. Header и страна
В Header: логотип, навигация, выбор страны (подпись «Страна»), счётчик корзины. Всегда виден код страны и валюта.
Выбор записывается в cc_region и читается при загрузке. Смена страны вызывает перезапрос меню и пересчёт корзины (это делают FE2 и FE3 через store).
Список стран приходит с API (GET /api/regions); до готовности API используй заглушку: UZB, KAZ, GEO, UKR, CHN.
