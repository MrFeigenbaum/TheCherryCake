3.5. Протокол сверки отчётов (неделя 4)
Создать через API 10–15 заказов с известными суммами в 3 регионах за 2 месяца (скрипт в Postman Runner, данные зафиксировать в /qa/seed-orders.json).
Выполнить SQL из документа BE2 §3.4 напрямую в БД — это эталон.
Для 3 наборов фильтров (все регионы/весь период; один регион; groupBy=MONTH) получить JSON, CSV, PDF.
Сравнить каждую ячейку: SQL = JSON.rows = CSV = PDF-таблица; KPI = суммам rows; averageCheck = total/ordersCount.
Проверить шапку PDF: фильтры и generatedAt присутствуют; все числа с 2 знаками.
Результат — таблица «ячейка / SQL / JSON / CSV / PDF / OK?» в verification-protocol-week4.md.
