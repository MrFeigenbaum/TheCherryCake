3.2. api/client.js — единая обработка ошибок
Request-интерцептор: если есть cc_token → заголовок Authorization: Bearer.
Response-интерцептор: ошибка → если body соответствует ErrorResponse — dispatch(ui/showToast({type:'error', message})) и reject с объектом {status, message, errors}; 401 → очистить auth, редирект на /login.
Страницы НЕ пишут свой try/catch для показа тостов — только для отображения errors под полями.

3.4. CountrySwitcher
При старте: regionSlice читает cc_region; если нет — VITE_DEFAULT_REGION; затем fetch /regions и выставляет объект региона.
Select с флагом/кодом и валютой: «🇺🇿 UZ · UZS».
onChange → dispatch(region/setRegion(code)) → записать cc_region → dispatch(cart/recalculate()) → страницы меню подписаны на region.code и перезапрашивают /products.
В шапке всегда видно: код страны и символ валюты.
Доступность: это обычный <select> с label «Страна», не кастомный div.

5. Что показываешь на демо
Неделя 1: витрина /ui-kit, переключатель страны пишет cc_region.
Неделя 2: смена страны — все цены в меню и корзине перерисовались без перезагрузки.
Неделя 3–4: правишь цену в админке → она видна в меню.
Презентация: 1 минута — дизайн-система и доступность (показать Tab-навигацию).
