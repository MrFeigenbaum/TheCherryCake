3. Детальные требования
3.1. Меню
Подписка на store.region.code: при изменении — getProducts({region, categoryId}). Показать Loader на время запроса, не мигать старыми ценами.
Вкладки категорий — role=tablist; активная категория в URL (?category=2), чтобы ссылка работала.
ProductCard: фото (object-fit: cover, фиксированная высота), название, цена formatMoney(price, currencyCode), кнопка «В корзину» (disabled + бейдж «Нет в наличии» при !isAvailable). Вся карточка — тач-цель ≥ 44 px.
Сетка: 1 колонка на 320, 2 на 768, 3–4 на 1200 (CSS grid + auto-fill, minmax(260px, 1fr)).
3.2. ProductModal
Открывается по клику на карточку; getProduct(id, region) → modifierGroups.
SINGLE → Radio-группа (если isRequired — без значения кнопка «Добавить» disabled и подсказка); MULTI → Checkbox.
Цена на лету: unitPrice = price + Σ priceDelta выбранных; total = unitPrice × quantity. Это единственное место, где фронт считает сам — для превью. В корзине всё берётся с API.
Quantity: Input type=number, inputMode=numeric, min=1, step=1; при вводе 0, отрицательного, дробного или текста — error и disabled «Добавить».
«Добавить» → dispatch(cart/addItem({productId, quantity, modifierIds})) → recalculate → тост «Добавлено» → закрыть.
3.3. cartSlice
state.cart = {
items: [{ productId, quantity, modifierIds: [] }],   // источник истины, пишется в cc_cart
totals: null | { currencyCode, items[], subtotal, vatRate, vatAmount, amountInclVat,
discountRate, discountAmount, deliveryFee, total },  // только с API
promoCode: null, orderType: 'PICKUP', deliveryZoneId: null,
status: 'idle' | 'loading' | 'error'
}
// thunks: addItem, updateQuantity, removeItem, applyPromoCode, setOrderType, setDeliveryZone → каждый вызывает recalculate()
// recalculate(): POST /cart/calculate { region: store.region.code, items, orderType, deliveryZoneId, promoCode }
3.4. Страница корзины
Таблица позиций (на 320 — карточки в столбик): название, список модификаторов, unitPrice, quantity (кнопки − / + и поле), lineTotal, удалить (aria-label=«Удалить <название>»).
Валидация quantity как в модалке; невалидное значение не отправляется на recalculate, подсвечивается, кнопка «Оформить» disabled.
Блок итогов CartSummary — строки строго в порядке: Subtotal, VAT (<vatRate·100> %), С НДС, Скидка (<rate> %) — показывать только если > 0, Доставка — только если orderType=DELIVERY, TOTAL. Каждая сумма с data-testid: cart-subtotal, cart-vat, cart-amount-incl-vat, cart-discount, cart-delivery-fee, cart-total.
Промокод: поле + «Применить»; ошибка 400 → текст под полем; успех → строка скидки.
Пустая корзина → EmptyState с кнопкой «Перейти в меню».
Кнопка «Оформить заказ» → /checkout (FE3).
3.5. Отчёты
Доступ: RequireRole VIEWER/STAFF/ADMIN.
Фильтры: DateRange (from, to — по умолчанию последние 30 дней), Select регион (все / список), Radio groupBy REGION|MONTH. Кнопка «Применить» → getSalesReport(filters).
KPI-карточки: subtotal, vatAmount, discountAmount, total, averageCheck — formatMoney.
Гистограмма 1: Chart.js bar, x = label (регионы или месяцы в зависимости от groupBy), y = total; второй dataset — ordersCount на второй оси (опционально). aria-label с кратким описанием; под графиком — таблица rows (та же data — это требование «график = агрегатам»).
Гистограмма 2: при groupBy=REGION показать дополнительно по месяцам с фильтром региона (две вкладки «По регионам» / «По месяцам»).
«Скачать CSV» → getReportExport({...filters, format:'CSV'}) → blob → ссылка download. «Сформировать PDF» → запрос PDF, показать «Готово» и кнопку «Скачать PDF» (блоб уже в памяти).
Состояния: loading (скелетон KPI), empty («Нет продаж за период»), error.

5. Что показываешь на демо
Неделя 2: меню → модификатор меняет цену → в корзину → смена страны → всё пересчиталось.
Неделя 3: промокод и порог скидки в корзине.
Неделя 4: отчёты — график, таблица, CSV, PDF.
Презентация: 2 минуты — демо меню и корзины; 1 минута — отчёты (с BE2).
