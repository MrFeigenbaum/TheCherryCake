3.2. Checkout — шаги
Шаг
Что на экране
Что в store / API
1. Контакты
Имя, телефон, email; если авторизован — предзаполнить из cc_user
local form state
2. Получение
Radio PICKUP / DELIVERY. PICKUP → Select точек (getPickupPoints(region)). DELIVERY → Select зон с тарифом в подписи («Центр — +5.00 UZS»)
dispatch(cart/setOrderType), cart/setDeliveryZone → recalculate → CartSummary справа обновляется
3. Дата и время
DatePicker (native <input type=date> с min=сегодня) → getTimeSlots(date) → кнопки слотов (role=radiogroup); !isAvailable → disabled + «занято»
timeSlotId, orderDate
4. Подтверждение
Сводка: позиции, способ, дата/слот, контакты; поле промокода; CartSummary; кнопка «Подтвердить заказ» (loading)
POST /orders → при 201: dispatch(cart/clear) → navigate(/order-success/:orderNumber); при 409 (слот заполнен) → вернуть на шаг 3 с ошибкой и перезапросить слоты
Stepper: шаги с aria-current=step; клик по пройденному шагу — назад можно, вперёд — только через «Далее».
На 320: CartSummary — под формой (collapsible «Итого: 255.04 UZS ▾»), на 1200 — справа sticky.
Экран успеха: номер заказа крупно, дата/слот, способ, кнопки «В кабинет» / «В меню». data-testid=order-success-number.
3.3. Booking
Поля: date (≥ сегодня), time (Select 10:00–22:00 шаг 30), guests (number 1–12), имя, телефон.
Отправка → POST /bookings. 409 → ErrorState-строка над кнопкой: «Нет свободного столика на это время, попробуйте другое» + фокус на time. 201 → карточка «Бронь №BK-… подтверждена, столик №N, <дата> <время>, <гости> гостей».
data-testid: booking-date, booking-time, booking-guests, booking-submit, booking-number, booking-error.
3.4. Auth и Account
authSlice: {token, user, status}; login → cc_token + cc_user; logout → очистить и redirect /. При старте приложения — восстановление из localStorage.
RequireAuth: нет токена → /login?next=<путь>. RequireRole: роль не входит → / + тост.
Account: вкладки; список заказов — карточки с Badge статуса (NEW серый, CONFIRMED синий, DONE зелёный, CANCELLED красный), раскрытие показывает позиции и полную разбивку сумм (те же 8 строк, что в корзине). Пусто → EmptyState «Вы ещё ничего не заказывали».

5. Что показываешь на демо
Неделя 2: регистрация → вход → выход; шаг 1 чекаута с ошибками валидации.
Неделя 3: полный заказ с доставкой и слотом; попытка выбрать занятый слот; бронь и 409; кабинет с историей.
Презентация: 1-2 минуты с BE2 — живое оформление заказа и бронь.
