3.2. PriceCalculatorService — сердце проекта
Один публичный метод. Его вызывают и /cart/calculate, и BE2 при создании заказа. Никто другой НДС и скидки не считает.
public CalculateCartResponse calculate(CalculateCartRequest req) {
Region region = regionRepository.findByCode(req.region()).orElseThrow(NotFound);
List<CartItemResult> items = buildItems(req.items(), region);  // unitPrice = regionalPrice + Σ priceDelta
BigDecimal subtotal   = sum(items, lineTotal).setScale(2, HALF_UP);
BigDecimal vatAmount  = subtotal.multiply(region.getVatRate()).setScale(2, HALF_UP);
BigDecimal amountInclVat = subtotal.add(vatAmount);
BigDecimal discountRate  = discountService.resolveRate(amountInclVat, region, req.promoCode());
BigDecimal discountAmount = amountInclVat.multiply(discountRate).setScale(2, HALF_UP);
BigDecimal deliveryFee = req.orderType() == OrderType.DELIVERY
? deliveryZoneRepository.findById(req.deliveryZoneId()).orElseThrow(NotFound).getFee()
: BigDecimal.ZERO;
BigDecimal total = amountInclVat.subtract(discountAmount).add(deliveryFee).setScale(2, HALF_UP);
return new CalculateCartResponse(region.getCurrencyCode(), items, subtotal, region.getVatRate(),
vatAmount, amountInclVat, discountRate, discountAmount, deliveryFee, total);
}
Ловушки
Порог скидки сравнивается с amountInclVat (с НДС), а не с subtotal. И строго ≥, не >.
Доставка добавляется ПОСЛЕ скидки — на неё скидка не действует.
Округляй после каждого шага, а не только в конце. Иначе фронт и PDF разойдутся на копейку.
Товар с isAvailable=false в регионе → 400 с errors {"items[2].productId": "not available in region UZ"}.
Обязательная группа модификаторов (isRequired) без выбора → 400.
Промокод просрочен/неактивен → 400 с понятным message, а не молчаливое игнорирование.
